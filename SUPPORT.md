# Support

Need help with a Hack SP project?

## Technical questions

If your question is about a specific repository, check its README and existing issues first.

If you found a bug or have an idea related to that repository, open an issue there.

## Hack SP questions

For questions about Hack SP itself, events, partnerships or anything that doesn't belong in a repository issue, contact us at:

**lucas@hacksp.org**
**diego@hacksp.org**
**contact@hacksp.org**

You can also learn more at:

**https://hacksp.org**

Please don't use GitHub issues for private, sensitive or security-related matters.
